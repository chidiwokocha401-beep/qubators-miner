**Qubators Cloud Miner** (educational BTC mining simulator):

**Core concept**

* Free, web-based, educational simulator — explicitly *not* real mining, no real money or crypto changes hands  
* Target: total beginners curious about crypto/mining basics  
* Guided, multi-stage curriculum: Basics → Economics → Network Effects

**Curriculum content**

* Stage-based lessons: text \+ diagrams/live charts  
* Short quiz at the end of each stage (gates progress)  
* Topics: what mining is, hash rate & blocks, electricity cost, ROI/break-even, halving, difficulty adjustment, pool vs. solo mining

**Core interactive mechanic**

* Visual rig/farm builder: users pick and "install" virtual ASIC rigs  
* Rigs modeled on real hardware specs and prices (for realism, no purchase needed)  
* Farm visually grows as users add/upgrade rigs

**Realism layer**

* Live BTC price, network difficulty, and hash rate pulled from a public API  
* Calculations (est. rewards, ROI, break-even) update against real conditions

**Engagement & progression**

* Full user accounts (email/password or social login)  
* Progress saved and synced across devices  
* Badges per stage completed \+ a final shareable certificate  
* Leaderboard (e.g., biggest virtual farm, fastest completion time)  
* Shareable certificate/badge (LinkedIn, X, etc.)

**Platform**

* Responsive web app (desktop \+ mobile browser)

One thing worth deciding before you build: what data source you'll use for live BTC price/difficulty (e.g., a free public API like CoinGecko or blockchain.info) — happy to help you pick one and sketch the technical architecture next, if you want to keep going.
